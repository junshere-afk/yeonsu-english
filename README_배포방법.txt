# Speed Speaking — GitHub Pages 배포용

이 ZIP의 파일을 압축 해제한 후 GitHub 저장소 최상위에 업로드하세요.
`index.html`과 `data/` 폴더의 위치를 유지해야 합니다.

GitHub 저장소 Settings → Pages → Deploy from a branch → main → /(root) → Save.
주소: https://junshere-afk.github.io/yeonsu-english/ (저장소 이름이 yeonsu-english일 때)

참고: 학습 기록은 브라우저 localStorage에 저장되므로 기기 간 자동 동기화되지 않습니다.
마이크는 HTTPS 환경에서 권한 허용이 필요하며 Chrome 등 Web Speech API 지원 브라우저에서 테스트하세요.

원본의 문제 데이터와 학습 로직은 수정하지 않았습니다.
